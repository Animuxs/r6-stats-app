What this is

R6 Match Stats turns a Rainbow Six Siege match replay into an R6 Pro League-style scoreboard: EPS, KD (+/-), Entry, KOST, KPR, HS, SRV, Clutches, Multikills, Objectives, Dead for trade kill and Trade kills for every player, plus a round-by-round breakdown.

This browser edition runs entirely in the page. The replay parser is r6-dissect compiled to WebAssembly, and the stats come from the Windows app's own Python code running in your browser, so the numbers match the app.

Where to find your replays

  • Turn on Match Replay in Siege's settings. The game saves each match as a folder named like Match-2026-09-25_22-55-04-8956, one .rec file per round.
  • The folder is Documents\My Games\Rainbow Six - Siege\<your id>\MatchReplay.
  • Drop the whole match folder, its round files, or a zip of them on Match report.

Your complete workspace

History, Ask, team and operator analytics, season tracking and themes are included here. Your browser saves confirmed matches on this device; export a workspace backup to move them. The Windows app also provides native docking and automatic replay-folder discovery. Download it from the project's releases page.
